# Royal Bangle Boutique

Act as a Senior Full-Stack Web Developer and UI/UX Designer. Build a complete, modern, responsive, and high-converting E-Commerce web application for a Bangle Brand named "[Brand Name - e.g., Kalai Bangles / Sundari Jewels]".

1. DESIGN & AESTHETIC:
- Theme: Royal, traditional yet modern Indian luxury aesthetic.
- Color Palette: Deep Maroon (#5C0A1E), Antique Gold (#D4AF37), Warm Ivory/Cream background (#FAF7F2), and Charcoal text (#1F1F1F).
- Typography: 'Playfair Display' or 'Cinzel' for elegant headings, and 'Plus Jakarta Sans' or 'Inter' for clean, readable body text and pricing.
- UI Style: Smooth hover zoom effects on product cards, subtle gold borders, glassmorphism sticky header, and mobile-first responsive design.

2. CORE PAGES & FEATURES:
- Home Page:
  * Top announcement bar (e.g., "Free Shipping across India on orders above ₹999 | COD Available").
  * Sticky Navigation Bar: Logo, Categories (Bridal Sets, Silk Thread, Glass Bangles, Gold Plated, Daily Wear), Search bar, Wishlist icon, User Profile, and Slide-over Cart drawer with item count.
  * Hero Banner: Full-width luxury banner showcasing bridal/festive bangles with a "Shop Collection" CTA button.
  * Shop by Category: Circular or arched image cards for Bridal, Silk Thread, Antique Gold, Glass, and Customized Name Bangles.
  * Bestsellers & Trending Carousel: Product cards showing image, title, material tag, price (in ₹ INR), original strikethrough price, discount badge, rating stars, and "Quick Add" button.
  * "Find Your Bangle Size" Interactive Guide section (explaining 2.2, 2.4, 2.6, 2.8, 2.10 sizes in mm/inches).
  * Customer Testimonials & Instagram Gallery grid.
  * Footer: Quick links, Customer Care, Return/Exchange policy, WhatsApp support button, and Newsletter signup.

- Shop / Collection Page:
  * Filter Sidebar (Mobile drawer on small screens): Filter by Category, Bangle Size (2.2, 2.4, 2.6, 2.8, 2.10), Color, Material (Brass, Copper, Glass, Silk Thread, Terracotta), and Price Range slider.
  * Sort by: Featured, Price: Low to High, Price: High to Low, Newest.

- Product Detail Page (PDP):
  * High-res image gallery with zoom-on-hover and multiple angles.
  * Product Title, SKU, Rating, Price in ₹, and stock status ("Only 4 sets left!").
  * Mandatory Size Selector pills (2.2, 2.4, 2.6, 2.8, 2.10) with a "Size Chart" popup modal.
  * Quantity selector, "Add to Cart", and "Buy Now" buttons.
  * Accordion tabs for: Product Description, Material & Care Instructions, Shipping & Returns.
  * "Complete the Look / Related Bangles" section.

- Cart & Checkout Flow:
  * Slide-out Cart Drawer with quantity +/- buttons, remove item, promo code input (e.g., "FIRST10"), and subtotal calculation.
  * Multi-step Checkout Page: Shipping Address form (with Indian Pincode, State dropdown), Delivery method, and Payment options UI (UPI/GPay/PhonePe, Credit/Debit Card, Net Banking, Cash on Delivery).
  * Order Confirmation screen with Order ID and summary.

- Admin Dashboard (Basic UI):
  * A `/admin` route to view total sales, manage orders (Pending, Shipped, Delivered), and add/edit/delete bangle products with size-wise stock tracking.

3. TECH STACK & DATA:
- Build using React, Tailwind CSS, and Lucide React icons.
- Include realistic mock data for at least 12 distinct Indian bangle sets with proper Indian Rupee (₹) pricing, sizes, and high-quality placeholder jewelry imagery (Unsplash).
- Use LocalStorage or State Management so the Cart, Wishlist, and Filters work seamlessly in real-time.
